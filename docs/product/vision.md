# Product scope

ARPEON aims to support local score reading, editing, accompaniment and instrument practice.
The architecture is instrument-neutral. Accounts, subscriptions, telemetry and remote
audio processing are not prerequisites.

Milestone 0 delivered the standalone tuner and engineering foundations. Milestone 1 added
MusicXML score display and local MIDI transport. Milestone 2 adds in-memory editing,
transformation previews, MusicXML export and a selectable flute MIDI voice with range checks.
Practice, reviewed web-source import, OMR, post-run analysis and live following are now present.
ML remains experimental until independent benchmark evidence supports product use.

The [roadmap addendum](roadmap.md) records flute and import acceptance criteria while keeping
the milestone order set by the attached specification.
