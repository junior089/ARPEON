# Dataset and fixture policy

No training dataset, model or recorded audio is included in Milestone 0. Test waveforms are
synthesized in memory from deterministic formulas/seeds. The MusicXML fixture is original
project test material under AGPL-3.0-or-later; see fixtures/README.md.

Before future additions, record source, rights holder where known, license, permitted uses,
redistribution/training restrictions, checksum and attribution. Never train on user imports
or microphone audio without explicit opt-in and sufficient rights. Unknown provenance blocks
that addition; it does not justify replacing it with copyrighted examples.

Milestone 3 bundles one unmodified flute fingering image from Wikimedia Commons under CC0 1.0.
The source lists the author as unknown and the SHA-1 as
`07f5b244b4f6148aaad5b05501761005cf5d6a5f`; see [third-party notices](../../THIRD_PARTY_NOTICES.md).
It is a visual reference, not a machine-readable alternate-fingering dataset. The exercise
generator contains original mathematical pitch patterns and no copied melodies or audio.
