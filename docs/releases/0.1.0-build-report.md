# ARPEON 0.1.0 — Windows build report

Date: 2026-10-09. Target: Windows x64 portable application.

## Verified locally

- `gradlew.bat build --warning-mode=fail` completed, including the Java test suites and formatting checks. A targeted OMR regression test also passed after the build.
- The Angular production build completed. Vitest passed 26 tests in 9 files after directing its temporary files into the workspace. The npm lockfile license and integrity check covered 586 entries.
- The automatic Audiveris setup downloaded the official 5.11.0 Windows MSI, matched its pinned SHA-256, extracted it into an isolated per-user test folder, launched `Audiveris.exe -version`, and reported `available_after=true` and `phase=ready`.
- Audiveris CLI converted a real five-page score PDF to MusicXML. Optical recognition is input-dependent: this particular output contains a tuplet and incomplete measures outside the editor's supported rhythmic model, so it was rejected for editing. No claim of accurate end-to-end transcription is made for that score.
- The packaged `ARPEON.exe` started on Windows and served the interface HTML and its JavaScript asset with HTTP 200. The package contains the Java runtime image, source archive, license and notices. The portable ZIP's SHA-256 matched the adjacent `.sha256` file.

## Limits

- The Windows executable has no Authenticode signature; no signing certificate was available for this local build.
- Audiveris is installed automatically on first use and requires a network connection for that initial setup. It is not bundled in the portable ZIP.
- Microphone, MIDI output and recognition quality on other machines or score scans were not verified here. Unsupported or inconsistent MusicXML remains an explicit import error.
