# ARPEON 0.1.0 — Windows portable release candidate

Date: 2026-10-09. Platform: Windows x64.

Extract the entire ZIP, then open `ARPEON.exe` inside the `ARPEON` folder. The package
includes a Java 25 runtime and the offline web interface; Java and Node installations are
not needed to run it. Keep the console window open while using the browser interface.
Use **Encerrar ARPEON** in the interface, close the launcher window, or press Ctrl+C to stop the local server. `LEIA-ME.txt` has Portuguese
instructions. The adjacent `.sha256` file contains the ZIP checksum.

This candidate contains the implemented tuner, score editing/playback, beginner practice,
local import, OMR review, performance analysis and live score following. The milestone 9
machine-learning candidate was evaluated against the deterministic follower and is not
enabled in the application. Local import caps are documented in
`docs/product/import-capabilities.md` inside `source.zip`.

MusicXML playback supports chords, independent voices, bounded non-nested repeats and
pass-specific endings. Written notation stays in its original measure order; repeat expansion
is applied to playback. Nested repeats/endings and unsupported notation remain explicit errors.

The normal score, tuner and practice flows work offline. Wikimedia Commons import needs
network access. On first use, PDF/image recognition can download and prepare the official
Audiveris 5.11.0 package in the user's local data folder from **Importar**. This step needs
network access; later recognition works offline.
Imported scores and later edits are saved automatically to a local project after a short
debounce. **Salvar projeto** remains available for an immediate save. Projects are stored
locally under the user's ARPEON data directory. The application uses the system default
browser rather than a native webview.

Score event details are fetched when a measure is opened, and the study list displays up to
48 events per page. The initial score response therefore avoids sending every event at once;
the notation renderer still loads the complete MusicXML document.

The app is AGPL-3.0-or-later. Its corresponding source is in `source.zip`; application
and third-party notices are adjacent. The bundled Eclipse Temurin runtime retains its
module licenses in `runtime/legal`. The runtime version is 25.0.4.1+1; upstream source
and build details are available from https://adoptium.net/temurin/releases/?version=25.

Local Windows validation and remaining device-specific limitations are recorded in
`docs/releases/0.1.0-build-report.md` inside `source.zip`. The executable is unsigned; there is no system installer in this
candidate. Real microphone, MIDI synthesizer, Audiveris recognition and large-file
performance depend on the target hardware and input files.
